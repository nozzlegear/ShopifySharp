ShopifySharp is an open-source library maintained in my spare time. If it's saved you time or helped you build something great, here are a few ways to support its continued development.

Working on open-source software is something that's very important to me, but it doesn't really pay the bills. That, unfortunately, means I can't always dedicate the time that I *want* to dedicate to developing ShopifySharp. With over 4M package installs and counting on Nuget, staying on top of bug fixes, feature requests and upstream changes from Shopify while answering questions and writing documentation has almost become a second job for me.

If you're using ShopifySharp in production – if it's saved you time, made you money on the Shopify App Store, or just helped you build something awesome – please support the project by helping fund its development!
